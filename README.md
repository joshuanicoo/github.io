# Joshua Gonzales portfolio

Plain HTML, CSS and a little JavaScript. No build step.

## Publish on GitHub Pages
1. Create a repository named `joshuanicoo.github.io` (this gives you https://joshuanicoo.github.io).
2. Upload everything in this folder to the repository root.
3. In the repository, open Settings, then Pages, set the source to "Deploy from a branch", choose `main` and `/ (root)`, and save.

## Before you publish
- Add your resume as `resume.pdf` in this folder, or remove the "View full résumé" link in `index.html`.
  Your current resume PDF includes your phone number. Remove it from the copy you upload if you don't want it public.
